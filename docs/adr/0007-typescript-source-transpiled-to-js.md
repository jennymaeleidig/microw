# TypeScript source, transpiled to plain JavaScript

microw's source of truth is TypeScript (`strict`), transpiled by `tsc` to plain JavaScript for distribution, so downstream consumers can use whichever language fits their needs: typed TS consumers import the shipped `.d.ts` types (or the `.ts` source itself), plain-JS consumers import compiled ESM or CJS. TypeScript is a dev-only dependency — the emitted JavaScript has zero runtime dependencies, preserving the zero-dependency claim. The package ships compiled ESM + CJS + `.d.ts` + source maps; a UMD single-file bundle is ruled out (no bundler in the pipeline). This deliberately reverses the fork's hand-written JS: the public API surface (options, callbacks, statics) becomes enforceable, exported types — the spec's API surface section carries those type definitions — and the headless DOM/CSS contract stays exactly as designed (ADR-0001–0006).
