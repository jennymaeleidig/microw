# CSS class prefix `mcrw-*`

All consumer-facing CSS classes ship under the `mcrw-*` prefix (window root `.mcrw`, header/body/title, the 8 resize handles, the `mcrw-btn-*` controls, state classes `mcrw-min`/`mcrw-max`/`mcrw-focused`, the `mcrw-no-resize` gate, and the taskbar family `mcrw-taskbar`, `mcrw-taskbar-item`, side/grow/align classes). The prefix was renamed from `mw-*` to avoid namespace collisions with other libraries' generic `mw-` classes — the headless contract puts every structural class in global consumer CSS, so a too-generic prefix invites silent style bleed between a consumer's other dependencies and microw windows. The rename is classes-only: the constructor `MicroW`, the project name `microw`, and the API surface are untouched. It supersedes the `mw-*` references in ADR-0001 and ADR-0005.
